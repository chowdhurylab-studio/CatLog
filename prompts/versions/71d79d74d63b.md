# Read one paper

You extract enzyme kinetic measurements from one paper. Input: `texts/<PMID>.txt` plus, if it exists, `texts/<PMID>.supp.txt` (the supplementary files). Full text; tables are
`=== Table N: caption` blocks with one ` | `-separated line per row, and `TABLE FOOT:` lines).
Output: write `work/<PMID>.read.json` and nothing else.

The original file (PDF or XML) is named in the `text_source` column of `papers.tsv`
(`grep "^<PMID>" papers.tsv`). For a PDF, the text is `pdftotext -layout`, so tables are laid-out text.
If a table is garbled (columns run together, a ± or exponent lost), re-render that page with
`pdftotext -f N -l N -layout <pdf> -`, or render it to an image in /tmp and look at it. Your `quote` must
still be copied from `texts/<PMID>.txt`; if a value is legible only in the image, skip it and say so in `note`.
Exception, a scanned PDF (OCR text layer) whose table cells are missing from the text: read those tables on the
rendered page images and extract every value, with `quote` = the table row as you read it, starting
`[page image p.N]`. The verifier re-reads each on the image; code flags such rows. Do not set `needs_supplement`
for a table you read this way (the verifier read 147 and 191 such values as "missed" in PMIDs 102640, 10965051).

If the text starts with `GLYPH WARNING`, this PDF's text layer replaces symbols (the line says which: µ printed as
`m` or `l`, ± as `6`, a superscript minus as `21` or `)1`, ° as `8`). Render every page with kinetic values
(`pdftoppm -r 200 -f N -l N -png <pdf> /tmp/p<PMID>`) and take each number, ±, unit prefix (µ vs m) and exponent
from the image. Write `raw_value` and `raw_unit` with the real symbols as the image shows them (`384 ± 6.2`, `µM`);
`quote` stays the text-layer copy (`38466.2 min21` is fine as the quote of `384 ± 6.2` min^-1).
A `TABLE IS AN IMAGE ONLY` line means that table's values are not in the text: if it likely holds kinetic values, set
`"needs_supplement": "article PDF: Table N is an image only"` (code then OCRs the article PDF and you read it again);
if the article PDF itself is on disk (`text_source`), read that table from its page images as above instead.

Extract EVERY kcat, Km and kcat/Km value the paper itself measured and prints as a number, for every
enzyme, variant, substrate and condition. Do not stop at a "main" table.

## Each row

```json
{"enzyme": "", "gene": "", "ec": "", "organism": "", "strain": "", "uniprot": "", "protein_ids": "",
 "variant": "", "substrate": "", "substrate_full_name": "", "cosubstrate": "",
 "metric": "kcat | Km | kcat/Km", "raw_value": "", "raw_unit": "",
 "pH": null, "temperature_C": null, "conditions": "", "metric_note": "", "construct": "",
 "location": "", "quote": "", "reasoning": ""}
```

- `raw_value`: the full printed cell, exactly as printed, including ± error or (n). `12.3 ± 0.4`, `1.2 × 10^5`.
- `raw_unit`: the unit exactly as printed in the cell, column header or caption, including any header
  multiplier such as `10^3 M^-1 s^-1`. Do not convert anything; code converts.
- `quote`: a verbatim span copied from the text file that contains the value — the table row line, or the
  sentence. It must contain the same number as `raw_value`. Copy, never paraphrase.
- `location`: `Table 2`, `Results p.4 paragraph on X`, `Figure 3 legend`, `Supplementary Table S1`.
- `variant`: `wild type`, or the mutation(s) in one-letter form with positions as printed (`Y123F`,
  `D45A/E78Q`), or a construct name if no mutation is given (`ΔN30`, `His6-tagged`, `chimera C2`). A natural form
  (isozyme, paralog, allele, splice or strain form: `β2β2`, `ADH1B*2`, `isozyme II`, `Form I`, `CMY-2`) is the
  enzyme's identity, not a variant: write its printed name in `enzyme` (in `gene` too when it is a gene name, and
  its own accessions in `protein_ids`) and `variant` is `wild type` (the user, 2026-10-10).
- `uniprot`: only if the paper prints a UniProt accession. Else "".
- `protein_ids`: every sequence ID the paper gives for THIS enzyme (GenBank/EMBL nucleotide or protein accession,
  RefSeq, PDB codes of this protein's own structures), comma-separated, exactly as printed; look in Methods
  ("deposited under accession ...", "GenBank MH000201"), figure legends and tables. Not homologs' IDs. Code uses them
  to find the right sequence (a printed PDB code gives the measured construct and its residue numbering).
- `gene`, `strain`, `ec`: as printed (EC from the paper or its title/abstract), else "".
- `organism`: the source organism of the enzyme (not the expression host). Leave it empty when the paper never says
  which species the enzyme came from, and say so in `note`: never put the expression host there. An empty organism
  does not lose the value. A species the paper gives for the enzyme itself IS the organism, however it is worded:
  `yeast X`, `human X`, `rat liver X`, `X from <species>`, `the <species> enzyme`, a species in the title or in the
  Methods sentence that says where this protein (or its gene) came from. A species named for something else is not:
  earlier work on another organism's enzyme, a homolog or comparison enzyme, a sequence alignment, the strain used
  for cloning or expression, or the source of a substrate or coupling enzyme. Never fill it in from a database or
  from what you know about the enzyme family.
- `substrate`: the varied substrate the value refers to, as printed; `cosubstrate` the fixed one, if stated.
  A reagent of a coupled detection system (NADH with an auxiliary dehydrogenase, PK/LDH, peroxidase dyes) is not a
  cosubstrate: put it in `conditions` as "coupled assay: ...".
- `substrate_full_name`: the full chemical name when the paper abbreviates it, from its abbreviation list,
  Methods or legend (`2Np-Gal` → `2-nitrophenyl beta-D-galactopyranoside`). Code looks up its SMILES.
  Keep stereochemistry and anomer. "" if the paper never spells it out and you are not certain.
- `reasoning`: one or two sentences on how you tied this value to its enzyme, variant, substrate and
  conditions (which table row/column, which Methods paragraph gave pH and temperature, any footnote).
- `pH`, `temperature_C`: from the assay conditions that apply to this value (Methods, caption or footnote);
  null if not stated. "Room temperature" or "ambient" is not a number: null, and put the words in `conditions`. A pH
  or temperature optimum from an activity profile is not the assay condition unless Methods say the kinetics were run
  at it. Use the pH and temperature of the enzyme reaction itself, not of a stop, colour-development/
  detection, pre-incubation, storage or stability step; when Methods give a standard assay and separate conditions
  "for kinetic analysis" or per substrate (a footnote "pH 9.0 for L-Arg"), use the ones for this value.
- `conditions`: the assay conditions of the measurement (buffer, metal, cofactor, method; e.g. `10 mM MgCl2`,
  `with 1 mM ATP`). Write the SAME text for the kcat, Km and kcat/Km of one measurement, so they stay together.
- `metric_note`: anything that applies to this one value only: `apparent`, `Hill fit, n = 1.8`, `paper-declared
  approximate value`, `kcat from Vmax/[E]`, `kcat per dimer` / `per active site` (only when the paper states the
  basis), a remark about this column's header. Never put these in `conditions`.
  A note you copy onto every row of a column must describe the column only, never cite one row's value.
- `construct`: the protein as the paper says it was expressed and measured, when that is not simply the full-length
  native protein: the residue range in the paper's own numbering (`residues 42-312`, `N-terminally truncated at
  Ser42`, `catalytic domain residues 1-350`, `lacking the first 30 residues`), fusions and tags (`His6-tagged`,
  `MBP fusion`), and the preparation when it is not a recombinant protein: `commercial (Sigma)`, `purified from
  bovine liver`. "" when the paper uses the full-length protein or says nothing. Code trims the stored sequence to a
  stated residue range, or leaves the sequence blank when it cannot place the range. Write the same `construct` text
  for every value of one protein; values of different preparations (native vs recombinant, tagged vs untagged, two
  truncations) get different `construct` texts, so code never pairs them.

## Rules

- First confirm the text is the paper you were given: the expected title is the third column of
  `grep "^<PMID>[[:space:]]" papers.tsv`. A related paper from the same group with overlapping title words is a wrong
  paper. An id like NP3F9A1C2B (NP + 8 hex) is a paper PubMed does not index: it is identified by the DOI in column 2
  and that title, never by PubMed; it is the right paper when the title matches and the article's own DOI (page 1
  header or footer), when printed, equals column 2. A different own DOI means a wrong paper.
  If it is a different article, write `"rows": []` and `"note": "wrong_paper: <what it is>"`.
- Only the target article: if the file also holds another article (the previous article's last page, a following
  article, an interlibrary-loan cover sheet), extract only from the pages of the article with the expected title.
- Never invent a number, quote or cell. Extract every value you can tie to its enzyme, variant and substrate; leave
  one out only when its identity, metric or unit is genuinely unclear, and say which and why in `note`.
- A value the paper prints as its own measurement but calls approximate, imprecise or "precarious" is still extracted,
  with the paper's words in `metric_note` (`paper-declared imprecise: ...`).
- Only values measured in THIS paper. Skip values the text attributes to other work ("as reported [12]",
  "from ref."), comparison tables of literature values, and predictions/simulations.
- kcat/Km: extract it only where the paper prints it. Never compute it yourself. A kcat/Km belongs to the substrate
  whose Km is its denominator (headers like `kcat/KM(A)` or `kcat/KM^NADH` say which): in a table that varies two
  substrates, file each efficiency under that substrate only. A kcat/(KmA·KmB) (units M^-2 s^-1) is not kcat/Km: skip.
- One printed kcat beside separate Km columns for two varied substrates: record it once, under the substrate whose
  saturation curve produced it (Methods/legend; else the substrate the row names). Do not copy it onto the other
  substrate unless the paper states that kcat for it too.
- "Km values for A, B and C were x, y and z, respectively": the n-th value belongs to the n-th name. Count positions.
- Hill constants (K0.5, S0.5, or an "apparent Km" from a Hill fit with n clearly ≠ 1), Ki, Kd, Kact, IC50,
  metal half-activation constants, Vmax and specific activity are NOT Km or kcat. Skip them. "Turnover number"
  and a Vm the paper defines as catalytic-centre activity are kcat; a bare Vm/Vmax (µmol/min/mg) is not.
  This holds even under a "Km"/"apparent Km" header: if the same table or paragraph gives a Hill coefficient clearly ≠ 1
  or calls the kinetics cooperative/non-Michaelis-Menten, skip that Km and its kcat/Km (kcat may stay, with
  "Hill fit, n = ..." in metric_note). A Km must be for a substrate the enzyme converts in that assay: the
  half-saturation constant of an activator, effector, metal or chemical-rescue agent (e.g. K_amine) is not a Km,
  and its kmax and kmax/K are not kcat or kcat/Km.
- kcat, Km and kcat/Km belong together only when they come from the same printed row and fit: same construct,
  substrate, cofactor (NAD+ ≠ NADP+), metal and condition. Each row stands alone; never mix blocks.
- Substrate names exactly as printed, with stereochemistry and cofactor (L-/D-, R/S, NAD+ vs NADH).
- Variant comes from the row's own label. A mutant value must never be recorded as wild type or vice versa.
- Text-layer glyphs: `40 600` is one number; `(1.6 ± 0.2)10^4` means ×10^4; `−` in an exponent is a minus;
  a lone `-` or `—` cell is empty, not a range. A `× 10` with no exponent means the superscript moved to an
  adjacent line: read it from the page image and write it (`3.6 × 10^5`, or `× 10^1` when the image truly shows none).
- A header multiplier (`×10^3`, `(10^-5 M^-1 s^-1)`) belongs to the column whose bracket it sits in. Put it in
  that column's `raw_unit` exactly as printed. If you cannot tell which column it belongs to, skip the column.
- "Apparent" Km/kcat are fine; note `apparent` in `metric_note`.
- Values only in a figure (bar/curve) without a printed number: skip.
- Ranges (`5–10`), lower/upper bounds (`>100`, `<0.1`), "ND", "n.d.", "—": skip.
- If one table row has kcat, Km and kcat/Km, that is three rows sharing the same quote.
- Keep table footnote markers out of `raw_value` (`12.3^a` → `12.3`), but read the footnote: it may change
  the conditions or say the value is from another source. A footnote marker on a column or row header
  ("Wild type^a") applies to every cell under it.
- When text and table disagree, use the table and mention it in the top-level `note`.

## File format

```json
{"pmid": "", "doi": "", "title": "", "note": "anything a verifier should know", "rows": [ ... ]}
```

If the paper has no measured kinetic values, write `"rows": []` with the reason in `note`.
If kinetic values the paper measured are only in supplementary material that is NOT in the text you were given
(e.g. "see Supplemental Table S1"), extract what is in the text and add `"needs_supplement": "<which file/table>"`
at the top level; the supplement is then fetched and the paper is read again.
